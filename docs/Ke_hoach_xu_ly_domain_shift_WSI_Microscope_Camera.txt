KẾ HOẠCH XỬ LÝ DOMAIN SHIFT
GIỮA WSI VÀ ẢNH MICROSCOPE-CAMERA

1. THÔNG TIN HIỆN TẠI

SOURCE DOMAIN – DỮ LIỆU HUẤN LUYỆN
- Patch gốc: 500×500 px
- Resolution: 0,48619 µm/pixel
- Physical FOV: 500 × 0,48619 = 243,095 µm
- Mỗi patch tương ứng khoảng 243,1 × 243,1 µm
- Classification: 500×500 -> 224×224
- Segmentation: 500×500 -> 256×256

TARGET DOMAIN – DỮ LIỆU ĐẠI HỌC Y DƯỢC
- Ảnh thực tế từ microscope-camera
- TIFF, 3840×2160
- Camera Sony IMX334
- Sensor pixel 2×2 µm
- Có mã bệnh nhân
- Có nhãn Gleason pattern của vùng ảnh
- Không có segmentation mask

2. MỤC TIÊU

Không train lại model từ đầu.

Mục tiêu là kiểm tra khả năng chuyển model đã train trên WSI sang ảnh microscope-camera, sau đó giảm domain shift bằng:
- Chuẩn hóa màu/ánh sáng
- Chuẩn hóa scale
- Fine-tuning nhẹ nếu cần

Hiện chưa có effective µm/pixel của camera tại mặt tiêu bản.

Chọn scale dựa trên validation patients, không dùng test set để chọn scale.

7. TISSUE / BACKGROUND DETECTION

Baseline:

def get_tissue_mask(img):
    gray = cv2.cvtColor(img, cv2.COLOR_RGB2GRAY)
    mask = gray < 220
    mask = mask.astype(np.uint8) * 255
    kernel = np.ones((5, 5), np.uint8)
    mask = cv2.morphologyEx(mask, cv2.MORPH_OPEN, kernel)
    mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, kernel)
    return mask

Tính tissue ratio:
tissue_ratio = np.mean(mask > 0)

Có thể bắt đầu với tissue_ratio >= 0,5 để loại patch có quá nhiều background, sau đó điều chỉnh bằng thực nghiệm.

8. CHUẨN HÓA MÀU/ÁNH SÁNG

Mục tiêu là giảm khác biệt giữa WSI scanner và microscope-camera.

Có thể bắt đầu bằng LAB/CLAHE:

def normalize_lab(img):
    lab = cv2.cvtColor(img, cv2.COLOR_RGB2LAB)
    l, a, b = cv2.split(lab)
    clahe = cv2.createCLAHE(
        clipLimit=2.0,
        tileGridSize=(8, 8)
    )
    l = clahe.apply(l)
    lab = cv2.merge([l, a, b])
    return cv2.cvtColor(lab, cv2.COLOR_LAB2RGB)

Sau khi baseline chạy ổn, có thể thử stain normalization chuyên dụng như Macenko hoặc Vahadane.

9. TẠO PATCH

Không lấy patch ngẫu nhiên; ưu tiên patch có đủ mô.

def extract_patch(img, x, y, size):
    h, w = img.shape[:2]
    x1 = max(0, x - size // 2)
    y1 = max(0, y - size // 2)
    x2 = min(w, x1 + size)
    y2 = min(h, y1 + size)
    patch = img[y1:y2, x1:x2]
    if patch.shape[0] != size or patch.shape[1] != size:
        return None
    return patch

Sau đó:
patch_500 = cv2.resize(
    patch,
    (500, 500),
    interpolation=cv2.INTER_AREA
)

15. FINE-TUNING

Chỉ thực hiện nếu baseline + preprocessing + scale matching vẫn chưa tốt.

Không train từ đầu.

Chiến lược:
1. Load model WSI-trained.
2. Freeze phần lớn backbone.
3. Fine-tune classification head.
4. Nếu cần, unfreeze một phần backbone cuối.
5. Dùng learning rate nhỏ.

Ví dụ:
for param in model.backbone.parameters():
    param.requires_grad = False

optimizer = torch.optim.AdamW(
    filter(lambda p: p.requires_grad, model.parameters()),
    lr=1e-4
)

Nếu cần mở layer cuối:
for param in model.backbone.layer4.parameters():
    param.requires_grad = True

Sau đó giảm learning rate, ví dụ 1e-5.

20. KẾT LUẬN

- Không train lại model từ đầu.
- Không resize trực tiếp 3840×2160 -> 500×500.
- Không tự giả định effective µm/pixel của camera.
- Giữ ảnh camera gốc.
- Chuẩn hóa ảnh -> tạo patch -> 500×500 -> 224×224/256×256.
- Đánh giá zero-shot trước.
- Fine-tune sau nếu cần.
- Classification có thể đánh giá định lượng vì có Gleason pattern.
- Segmentation hiện chỉ đánh giá định tính vì chưa có mask.
- Chia dữ liệu theo bệnh nhân để tránh data leakage.
